
# PARALLEX_EFFECT
Adventure-themed web page with parallax scrolling and layered background effects. Showcases activities like biking, paragliding, and surfing with styled headings and descriptive text. Built using HTML and CSS to create an immersive and interactive experience.


Project Overview:-
This project is a visually striking parallax website that highlights adventure sports including biking, paragliding, and surfing. Made with HTML and CSS, the website utilizes layered images and CSS transforms to create a dynamic scrolling effect. The goal is to offer an immersive digital experience showcasing adventure themes.

Features:-
Parallax scrolling with multi-layer depth.
Adventure sports sections: biking, paragliding, surfing.
Responsive design, works across devices.
Clean and modern aesthetic.
